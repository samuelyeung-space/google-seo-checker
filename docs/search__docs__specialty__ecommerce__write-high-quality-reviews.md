# 撰写优质评价

 发布优质评价可以帮助用户详细了解正在了解的事物，例如商品、服务、目的地、游戏、电影或其他主题。例如，您可以如下身份撰写评价：

- 在竞品之间引导用户的专业人士或商家。
- 发表独立观点的博主。
- 新闻或其他发布网站的编辑人员。

 为帮助用户在 Google 搜索和其他 Google 平台上发现您的商品评价页面，请遵循以下最佳实践：

- 从用户的角度评估。
-  展示出您对评价对象了如指掌，表明您是这方面的专家。
-  提供相应证据，例如有关您自己的评价对象使用体验的影像内容、音频或其他链接，以证明您的专业知识并强调评价的真实性。
-  分享量化衡量数据，说明评价对象的各方面表现为何符合标准。
- 说明评价对象在哪些方面优于其竞争对手？
-  包含可供考虑的对比对象，或说明哪些对象可能最适合某些用途或情形。
- 根据您自己的原始研究内容探讨特定评价对象的优缺点。
-  介绍商品如何从之前的型号/版本演变而来，说明商品的改进之处、解决的问题或以其他方式帮助用户做出购买决策。
-  根据您的经验或专业知识，重点关注最重要的决策因素（例如，某汽车评价可能认为油耗和安全性是挑选汽车的关键决策因素，并对某款汽车在这些方面的表现做出了评分。）。
-  介绍商品设计方面的关键选择，以及除制造商已声明的影响外，这些选择对用户还会有什么影响。
-  添加指向其他实用资源（您自己的资源或来自其他网站的资源）的链接，帮助读者做出决定。
-  考虑添加指向多个卖家的链接，以便读者能够自行选择商家来购买商品。
-  推荐某个对象综合表现出众或某方面尤其出众时，请附上您觉得该对象最佳的原因，并附上第一手证明。
-  确保排名列表可提供足够的实用内容，让各评价对象都有独立的说明，即便您选择分别撰写深入的单独评价也应尽量这么做。

 评价通常会使用联属营销链接，这样一来，如果用户认为评价很有用，并通过提供的链接购买商品，评价者就会获得卖家提供的奖励。为此，另请参阅 [Google 在联属营销计划方面的立场](https://developers.google.com/search/docs/essentials/spam-policies?hl=zh-cn#thin-affiliate-pages)。

 评价是用户做决定的绝佳参考资源。在撰写评价时，应尽可能多地遵循上述最佳实践，重点关注评价的质量和原创性，而不是篇幅的长短。这将会为阅读评价的用户带来最大价值。
