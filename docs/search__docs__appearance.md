##  使用结构化数据

 Google 利用结构化数据了解网页上的内容。您可以向我们提供关于您网站的具体信息，这样，您的网站显示在搜索结果中时可以使用更丰富的功能。

- [Google 搜索支持的结构化数据标记列表](https://developers.google.com/search/docs/appearance/structured-data/search-gallery?hl=zh-cn)
- [了解结构化数据的工作原理](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data?hl=zh-cn)
- [使用 JavaScript 生成结构化数据](https://developers.google.com/search/docs/appearance/structured-data/generate-structured-data-with-javascript?hl=zh-cn)
